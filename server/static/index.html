📘 新手安装与使用指南

一、电脑端必备依赖

  • Android Studio（建议 2024.1+）
  • Python 3.7+（建议 3.10+）
  • ADB（Android Platform-Tools）

二、Python 依赖安装

macOS / Linux
python3 -m pip install -r server/requirements.txt
Windows
python -m pip install -r server/requirements.txt

三、ADB 快速检查

adb version && adb devices

如果提示找不到 adb：请在 Android Studio > SDK Manager 安装 Platform-Tools，并把 platform-tools 加入 PATH。

四、设备连接前检查

  • 设备已开启开发者选项 + USB 调试
  • 首次连接已在设备上点“允许 USB 调试”
  • 执行 adb devices 能看到 device 状态
